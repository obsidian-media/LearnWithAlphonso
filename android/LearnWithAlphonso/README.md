# Learn with Alphonso for Android

The native Android app. Kotlin, Jetpack Compose, Material 3, against the
same Supabase project, Edge Functions and `/api/*` routes the iOS app and the
web app use. Design: `docs/superpowers/specs/2026-09-29-android-app-design.md`.
Plans: `docs/superpowers/plans/2026-09-29-android-plan-1-*.md` and follow-ons.

## Modules

| Module | What it holds | Tests |
| --- | --- | --- |
| `core` | Pure JVM Kotlin. Content models and loud-failing JSON decoding, ports of the shared TS/Swift logic (SRS, hearts, progress math, spoken and written answer matching in EN/FR/ES, question grading, placement, vocab derivation, reinforcement pick, review badge), the Supabase and API clients over Ktor, the offline sync engine, the session state machine. | JUnit 5, `./gradlew :core:test`. Every port carries the same vectors as its TS test file. |
| `app` | Compose UI (four themes with dark variants, the seven bundled OFL fonts), encrypted session store, Room offline queue, connectivity, navigation, screens. | JUnit 4 view-model tests, `./gradlew :app:testDebugUnitTest`; Room and launch smoke tests run on CI's emulator, `connectedDebugAndroidTest`. |

Content JSON in `app/src/main/assets/content/` is generated by
`bun scripts/export-android-content.ts` at the repo root and is byte-identical
to the iOS bundle. CI fails on drift. Core tests read the same directory as a
test resource root, so there is one copy in git.

## Building locally

See `TOOLING.md`. Short version: set `ANDROID_HOME`, `GRADLE_USER_HOME` and
`JAVA_HOME` to the playground paths, then `./gradlew :app:assembleDebug`.
There is no emulator on the development machine; anything device-shaped is
verified by `.github/workflows/android-ci.yml`'s emulator job or by the owner
on a phone.

## Deviations from the spec worth knowing

- Auth talks to the GoTrue endpoints directly through a small Ktor client in
  `core` (the same wire contract as `SupabaseAuthClient.swift`) instead of
  supabase-kt. It keeps the session state machine JVM-testable and the
  dependency list short; nothing user-visible changes.
- `compileSdk` is 37.2, not 36: current AndroidX artifacts refuse to compile
  against 36. `targetSdk` stays 36 as Play requires.

## Secrets (none needed yet)

Set in the repository's GitHub secrets during Plan 5, never committed:
`ANDROID_UPLOAD_KEYSTORE_BASE64`, `ANDROID_UPLOAD_KEYSTORE_PASSWORD`,
`ANDROID_UPLOAD_KEY_ALIAS`, `ANDROID_UPLOAD_KEY_PASSWORD`,
`PLAY_SERVICE_ACCOUNT_JSON`, `REVENUECAT_ANDROID_PUBLIC_KEY`,
`FIREBASE_GOOGLE_SERVICES_JSON`, `FCM_SERVICE_ACCOUNT_JSON`, `FCM_PROJECT_ID`.

The Supabase URL and publishable key in `app/build.gradle.kts` are public
client values, the same ones `AppConfig.swift` ships.

## One owner action before Google sign-in works on a device

Add `com.obsidianmedia.learnwithalphonso://login-callback` to the Supabase
project's allowed redirect URLs (Authentication, URL Configuration). Without
it the Custom Tab completes at Google and Supabase refuses the redirect.
